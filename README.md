# 本地音乐（macOS）

参考安卓 RPlayer 做的 Mac 本地音乐播放器，SwiftUI 原生开发，需要 macOS 14 或更新版本。

## 编译运行

需要先装好 Xcode（App Store 免费下载），装完打开一次让它装好组件。

**方法一：用 Xcode 打开（推荐，方便调试）**

1. 双击这个文件夹里的 `Package.swift`，会用 Xcode 打开。
2. 等左上角的进度跑完，点左上角的 ▶ 运行。

**方法二：打包成 .app**

在终端里运行：

```bash
cd ~/Documents/"music app project"
./build-app.sh
```

它会编译、打包，并自动安装到「应用程序」文件夹（`/Applications/本地音乐.app`），`build/本地音乐.app` 里也留一份。如果旧版本正在运行，会先退出它，装好后再打开新版本。

以后改了代码，再运行一次 `./build-app.sh` 就会更新。音乐库、歌单、收藏、设置和下载的封面/歌词都在 `~/Library/Application Support/LocalMusic/`，更新 App 不会丢。

## 现在有的功能

- **歌曲库**：添加一个或多个音乐文件夹，自动扫描（包括子文件夹）。支持 MP3、FLAC、M4A/ALAC、AAC、WAV、AIFF。
- **五个分类**：歌曲、列表（我的收藏 + 自建歌单）、专辑、艺术家、文件夹。
- **拼音 / 英文首字母排序**：中文按拼音、英文按字母，统一按 A–Z 分组，右侧有字母索引；也能按歌手、专辑、时长、修改时间排序，可倒序。
- **搜索**：歌名、歌手、专辑，也支持拼音（`qingtian`）和拼音首字母（`qt`）。
- **音质标签**：SQ（无损，16bit）和 HR（高解析，24bit 或高于 48kHz）。
- **封面**：优先用文件内嵌封面，其次同文件夹里的 `cover.jpg` / `folder.jpg`，都没有才联网下载（先 iTunes 搜索接口，找不到再用酷狗）。
- **歌词**：优先用文件内嵌歌词，其次同名 `.lrc` 文件（支持 GBK 编码），都没有才联网下载（先酷狗，找不到再用 LRCLIB；酷狗是非官方接口，失效时自动跳过）。
- **正在播放页**：圆形封面 + 模糊背景、当前一句歌词、收藏 / 随机 / 循环 / 播放队列 / 睡眠定时、进度条、快退 / 上一首 / 播放 / 下一首 / 快进、"下一首"提示。
- **歌词页**：同步滚动，当前行高亮，点某一行跳到那里。
- **其它**：底部迷你播放条、播放队列（下一首播放、移除）、睡眠定时、键盘媒体键和控制中心、空格播放/暂停、⌘← / ⌘→ 切歌、Esc 收起播放页。

## 数据存放位置

`~/Library/Application Support/LocalMusic/`：音乐库索引、歌单收藏、联网下载的封面和歌词缓存。删掉这个文件夹就是重置。

## 代码结构

```
Sources/LocalMusic/
  LocalMusicApp.swift        程序入口、菜单、快捷键
  Models/Track.swift         歌曲、歌单数据结构
  Library/                   扫描音乐库、读取标签、拼音排序、FLAC/LRC 解析
  Player/PlayerController    播放、队列、随机循环、睡眠定时、媒体键
  Online/                    封面 / 歌词的加载顺序和联网获取
  Views/                     界面
```
