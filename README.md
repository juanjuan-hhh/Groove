# Groove（macOS 本地音乐播放器）

原生 SwiftUI 写的 Mac 本地音乐播放器。
需要 macOS 14 或更新版本。


## 下载安装

下载 `Groove-v1.3-macOS.dmg`，拖入「应用程序」。

App 没有经过 Apple 公证，第一次打开时系统会提示「Apple 无法验证"Groove"是否包含恶意软件」。需要手动放行一次：

1. 在提示框里点「完成」（不要点「移到废纸篓」）。
2. 打开「系统设置 → 隐私与安全性」，拉到底部，找到「已阻止"Groove"以保护 Mac」，点「仍要打开」，输入开机密码。
3. 再打开一次 Groove，在弹出的提示里点「打开」。

如果无法打开；或者提示「已损坏」：
在「终端」里运行下面这行命令后再打开：

```bash
xattr -cr /Applications/Groove.app
```

支持 Apple 芯片和 Intel 芯片的 Mac，需要 macOS 14 或更新版本。

## 功能

- **歌曲库**：添加一个或多个音乐文件夹，自动扫描（包括子文件夹），每天扫描一次。支持 MP3、FLAC、M4A/ALAC、AAC、WAV、AIFF。
- **分类**：歌曲、歌单（我的收藏 + 自建歌单）、专辑、歌手、文件夹。
- **拼音 / 英文首字母排序**：中文按拼音、英文按字母，统一按 A–Z 分组，右侧字母索引可以拖动；也能按歌手、专辑、时长、修改时间排序。
- **搜索**：歌名、歌手、专辑，也支持拼音和拼音首字母。
- **音质标签**：SQ和 HR。
- **封面和歌词**：优先采用文件内嵌、同文件夹`cover.jpg` / 同名 `.lrc`，文件若未自带则联网获取。也可以手动「联网搜索封面和歌词」；App 内下载文件可以一键删除，不涉及音乐源文件。
- **正在播放 / 歌词页**：旋转封面 + 封面色模糊背景，歌词同步滚动、单行点击跳转，可以微调歌词快慢。
- **悬浮球**：启用悬浮球：显示上一首 / 播放暂停 / 下一首；拖到屏幕边缘自动贴边；同时胶囊显示当前一句/两句歌词；大小右键悬浮窗，支持刘海贴边，状态栏显示歌词。
- **其它**：支持app音频独占

## 数据存放位置

`~/Library/Application Support/LocalMusic/`：音乐库索引、歌单收藏、联网下载的封面和歌词缓存。删掉文件夹即可重置。
